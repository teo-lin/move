# Move

Private Android exercise app for personal use. Package id: `app.move.kineto`.

The app is intentionally local-only:

- no `INTERNET` permission
- no ads SDK
- no analytics SDK
- no Firebase/Sentry/billing dependencies
- bundled exercise GIFs from `assets/exercises`

## Phase 1 Behavior

Workouts are guided and timed:

- each exercise has repetitions, seconds per repetition, and position in the workout
- exercises can be moved up/down in the workout setup list
- repetitions and seconds per repetition can be adjusted before starting
- the runner speaks the exercise name
- it plays five countdown clicks, says "Go", then chimes at the configured repetition rhythm
- two-sided exercises pause halfway, say "Change side", count down again, then continue
- each exercise auto-advances when its timed repetitions finish
- the runner controls are icon-only: previous, repeat, pause/resume, next, finish
- finishing the last exercise automatically saves the workout to local history
- step settings (order, reps, seconds, two-sided) are saved on the device; "Reset to default settings" restores the bundled routine

## Phase 2 Features

- **Routines:** PeSpate: abs, PatruLabe: upper body, Core-First A (L1), Core-First B (L2) from `body/sessions.md`, and Office: micro. "N/side" moves run N reps per side with a "Change side" cue at the midpoint.
- **European calendar:** History shows a month calendar with weeks starting on Monday, sessions grouped by local day, and dates as `dd.MM.yyyy`. The CSV keeps the baseline's `yyyy.MM.dd`.
- **Stats:** sessions this week (Monday–Sunday) and this month, totals, and per-workout counts, plus Export and Share for the CSV.
- **Own exercise media:** `121 Wall push-up.gif` is original artwork generated by `scripts/make-wall-pushup-gif.py`. Run `npm run generate:exercises` after adding GIFs to `assets/exercises`.
- **Catalog detail:** tap an exercise to see its animation and which workouts use it.
- **Launcher icon:** "Stretch" (spine, head and motion arc on a green gradient), generated by `npm run generate:icon` as an adaptive icon with a themed-icon monochrome layer, plus legacy PNGs.
- **Runner:** a segmented progress bar (one segment per rep, the current one fills in real time, with a gap at the side change). The screen stays on for the whole workout.
- **Catch your breath:** set "Rest between exercises" (0–180 s, in 5 s steps) per workout. During a run, the ≈ button starts a 20 s breather and then repeats the current exercise; tapping it again adds 15 s, and › skips the rest.
- **Sounds:** soft synthesized cues (`CueSounds.kt`): a light tick for the countdown, a muted woodblock for each rep, a three-note marimba chime when an exercise ends, and a two-note chime when a rest ends. No audio files are bundled.
- **History cleanup:** long-press a session in History to delete it, for example test runs you don't want in the CSV.

## Build

Install Android Studio or a local Android SDK/JDK toolchain, then install JavaScript dependencies:

```powershell
npm install
```

Build:

```powershell
cd android
.\gradlew.bat assembleDebug
```

The debug APK is produced under:

```text
android/app/build/outputs/apk/debug/
```

Install on a connected phone:

```powershell
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

The debug build uses package id `app.move.kineto.debug`, so it can coexist with the eventual signed release build.

## Release Signing

Create a release keystore outside git:

```powershell
keytool -genkeypair -v -keystore C:\_____\_SECRETS\move-release.jks -alias move -keyalg RSA -keysize 4096 -validity 10000
```

Copy `android/keystore.properties.example` to `android/keystore.properties`, fill in the passwords, then build:

```powershell
cd android
.\gradlew.bat assembleRelease
```

The release APK is produced under:

```text
android/app/build/outputs/apk/release/
```

Install or upgrade:

```powershell
adb install -r android/app/build/outputs/apk/release/app-release.apk
```

Keep the same keystore forever. Android treats a build signed by a different key as a different trust line and will not install it over the existing release app.

## GitHub Releases

The workflow in `.github/workflows/android-release.yml` builds on tags named `v*`.

For signed release APKs in GitHub Actions, add these repository secrets:

- `MOVE_KEYSTORE_BASE64`: base64 contents of `move-release.jks`
- `MOVE_STORE_PASSWORD`
- `MOVE_KEY_ALIAS`
- `MOVE_KEY_PASSWORD`

Then tag and push:

```powershell
git tag v0.1.0
git push origin v0.1.0
```

The workflow uploads `move-v0.1.0.apk` to the GitHub Release.

## CSV Export

The app exports session history to:

```text
/sdcard/Download/move/back-exercises.csv
```

Tap **Stats → Export CSV** on the phone, then merge it into the health repo:

```powershell
npm run sync:csv              # adb pull + merge into C:\_____\_CODE\body\baseline\back-exercises.csv
npm run sync:csv -- --dry-run # preview the rows that would be added
```

The sync merges instead of overwriting, so older rows recorded in the original Kineto app are kept. Rows the baseline already has are skipped, and the result is sorted newest first. Workout names use the baseline's emoji labels (for example `🦦 PeSpate: abs`).

**Stats → Share CSV** sends the same CSV through the Android share sheet.
